# ARCH After URLinking – Plan

A plugin that turns a pasted link into the right kind of link: a link to the note
that already exists for it in another vault, or, when there is none, a web link
with the page's title. It takes over the job of Auto Link Title. Its main home
will be THOUGHTS, where thoughts link to notes in other vaults (a YouTube video
note in TECHNOS, a Reddit thread note in GENERALS, a concept in Psycho-history).

Why it exists: cross-vault wikilinks do not resolve, and typing
`obsidian://open?vault=…&file=…` by hand is a nightmare. The six cross-vault links
in the Grand Strategy (September 2026) were generated by a script for that reason.

## What a paste becomes

| You paste | It becomes |
|---|---|
| A web URL that has a note in another vault | `[Note title (Vault: Vault name)](obsidian://open?vault=…&file=…)` |
| A web URL with no note anywhere | `[Page title](https://…)` |
| An `obsidian://` URL copied from another vault | `[Note title (Vault: Vault name)](obsidian://…)` |
| An `obsidian://` URL from this same vault | `[[Note title]]` |

With text selected, the selection becomes the link text instead of the title.

- **A note is found by its source URL**, the `url` property that After Clipping, YT
  Playlists and X Twitter write (`url`, `URL` and `source` to start, a setting).
  About 1,600 notes across the vaults carry one.
- **Matching ignores what does not matter**: `youtu.be` and `youtube.com/watch` are
  the same video, `twitter.com` is `x.com`, `www.`/`old.`/`m.` and tracking
  parameters (`utm_…`, `si`, `fbclid`) are dropped.
- **The web link is not written beside the note link** unless you turn on *Keep the
  web link beside a note link*. It was on at first; you turned it off by default on
  2026-09-26: *"I think it should be turn off by default becaue It does clutter the
  note visual."* With it on, a `[↗](https://…)` follows the note link.
- **The vault's name is in the link text**, as *Note name (Vault: Vault name)*, your
  format of 2026-09-26 *"for better visual clarity"*, so you see where a link goes
  while reading.
- **Titles come from the site's own title service where the page lies about it.**
  A YouTube page's title reads " - YouTube" to a script (Auto Link Title's usual
  failure); YouTube's oEmbed gives the real one. X gives the post's text.
- **Reddit cannot be reached from the Mac**: the network provider's DNS answers
  `127.0.0.1` for `www.reddit.com`, and `old.reddit.com` refuses scripts. The title
  is read from the address itself instead
  (`r/Stoicism – Epictetus said freedom is secured not by the`).
- **A title that is only the site's name** ("Instagram", "Gemini") is not a title;
  the link is left as a plain URL for you to name.

## Decided

- **Tested in TESTFIELD first**, not THOUGHTS (your choice, 2026-09-26). Auto Link
  Title is turned off there for the test, since two plugins rewriting one paste
  fight each other. THOUGHTS, and any other vault, only after it has proved itself.
- **In THOUGHTS since 2026-09-26**, after you clicked the test links and they opened.
  Installed through BRAT, with Ideaverse, Archive and TESTFIELD left out and Auto
  Link Title turned off there.
- **The links already in THOUGHTS are converted later, by hand, with Claude's
  help**: go through the thought notes and month notes entirely and create notes
  for their links first. Today only 58 of THOUGHTS' 1,468 links (23 distinct pages)
  have a note in another vault, so a bulk conversion now would change little.

- **Old copies are never linked to** (your choice, 2026-09-26: *"exclude them to keep
  things simple"*): Ideaverse, Archive and TESTFIELD are left out in the plugin's
  settings, and the Documents vault excludes `backup-strategy/_before-video-move/`.
  The setting belongs to each vault, so THOUGHTS needs the same three when it gets
  the plugin. 12 addresses still have two notes, all in vaults you use (five CHAOS
  films with an old copy in `_/Old Film Notes`, a few doubled downloads, split
  iCanStudy pages, *The Acceleration (Safe)*); for those a menu asks which note.
